## Services

| Service | Used for |
| --- | --- |
| PayPal sandbox (Vault v3, Orders v2, Payments v2, Webhooks, JS SDK v6) | saving the parent's PayPal, charging it, refunding, event notifications |
| PayPal Agent Toolkit (`@paypal/agent-toolkit`) | the agent's `create_order`, `get_order` and `create_refund` tools |
| PayPal Server SDK (`@paypal/paypal-server-sdk`, generated by APIMatic) | Vault calls, seed purchases, capture and refund lookups |
| APIMatic PayPal Context Plugin | the integration workflow and contract sheet in `paypal-plan.md` |
| Channel3 (`@channel3/sdk`) | product search, image search, similar products, product detail |
| W&B Inference | the language and vision models, through the OpenAI-compatible API |
| ElevenLabs | the video narration and Kip's pre-rendered voice lines |

Product titles, images, prices and store names shown in the live app come from Channel3 and belong to their owners.
The demo video and the screenshots were recorded in the app's recording mode (`?safe=1`), which masks store domains and
removes brand names from titles.
