# APIMatic PayPal Context Plugin skills (TypeScript)

These are the TypeScript skills from APIMatic's PayPal Context Plugin
(`context-plugins/plugin-marketplace`, `plugins/paypal/skills/typescript`,
plugin version 0.4.1, MIT license, see `APIMATIC-LICENSE.txt`).

They were copied in from a clone of that repository rather than installed with
`npx skills add`, because the build sandbox did not allow running the remote
installer. The only edit is typographic: long dashes were replaced with
hyphens to match this repository's writing rules. The content is otherwise
unchanged.

How they were used while building the PayPal integration is described in the
README (section "Sponsor tools") and in `paypal-plan.md`.
